# Trekking Management Application - V2

This is a web application to manage trekking routes, assign staff members, and allow trekkers to book routes.

## Roles
- Admin: Pre-created user to manage treks and staff.
- Trek Staff: Assigned to treks to update status and slots.
- User (Trekker): Self-registering users who book treks.

## Tech Stack
- Backend: Flask, Flask-SQLAlchemy, SQLite
- Frontend: Vue.js, Bootstrap
- Background Tasks: Celery with Redis
- Performance: Redis Caching
